display: grid
One property turns a normal container into a grid. Without it, children stack vertically like a list. With it, you control rows and columns. Nothing else changes until you add more grid rules.
💡 Real world: A classroom seating chart — rows of desks from front to back, columns of desks side to side. The moment you say "this is a grid," the browser treats every child as a cell in that chart.

grid-template-columns
Defines how many columns the grid has and how wide each one is. Each value = one column. Three values = three columns. You can mix fixed widths (200px) with flexible ones (1fr).
💡 Real world: A building floor plan — one narrow label column for the floor name and three equal room columns: 80px repeat(3, 1fr). The label stays fixed; the rooms share the remaining width equally.

03
grid-template-rows
Same idea as columns but for rows. Set each row to a fixed height, let it fit content (auto), or fill available space (1fr). Rows default to auto — you mostly set them for full-page layouts.
💡 Real world: A school building with two floors — each floor is one row. The label row shrinks to fit the text; the room rows share the remaining height equally: auto auto.

04
gap
The space between grid cells. One value = same gap everywhere. Two values = row gap first, then column gap. It only applies between cells — never outside the grid edges.
💡 Real world: Gaps between rooms on a floor plan — the walls between rooms. Every room gets the same wall thickness without you calculating anything: gap: 12px.

05
The fr unit
fr = fraction of available space. 1fr 1fr = two equal columns. 1fr 3fr = second column is three times wider. The fr unit only exists in CSS Grid — it does not work anywhere else.
💡 Real world: A canteen with a small serving counter and a large dining area: 1fr 3fr. The dining area is always three times the counter's width, no matter how wide the room is.

06
repeat()
repeat(3, 1fr) is shorthand for 1fr 1fr 1fr. First value = how many columns. Second = width of each. Keeps CSS readable when you have many equal columns. Change one number to change everything.
💡 Real world: Six lockers side by side in a corridor: repeat(6, 1fr). All six are exactly the same width. Change 6 to 4 and you have four wider lockers — zero other changes needed.

07
grid-column: span
grid-column: span 2 makes one item stretch across two columns. You apply this to the child — not the container. Everything else reflows around the spanning item automatically.
💡 Real world: A notice board where the top notice is pinned across all three columns — it reads "URGENT" and is wider than the rest. All other notices sit below it in their normal single-column slots.

08
grid-template-areas
Name each region in plain words, then draw the layout using those names. The ASCII art in your CSS literally IS the layout. Read it and you immediately see where every region goes — no numbers needed.
💡 Real world: An architect's floor plan drawn in words — "entrance", "hall", "office", "bathroom". Move the office to the other side of the hall by changing the word positions. Zero rooms need to be physically rebuilt.

09
auto — content-sized tracks
auto means "make this track as big as it needs to be for its content." For rows, this is the default — each row is as tall as its tallest cell. Combine with 1fr to make one track stretch and others hug their content.
💡 Real world: A school building layout: the floor-label row is just tall enough to show "1st Floor" text (auto), the room rows share the remaining height equally (1fr): grid-template-rows: auto 1fr auto.
