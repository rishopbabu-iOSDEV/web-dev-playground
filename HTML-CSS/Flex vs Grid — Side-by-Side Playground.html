Row of items
The most basic case — putting boxes side by side. Both can do it, but the why is different.
🏫 School analogy: Desks in a row. Flex arranges them along one corridor. Grid places them in a pre-drawn grid on the floor plan.

CSS Grid

02 / 08
Centering a single item
One box, centered perfectly. Both do it — but Grid does it in one line. Flex needs two.
🏫 School analogy: Placing a trophy at the exact center of the display case. Grid knows the center precisely. Flex has to push from both ends.
Flexbox
Trophy 🏆
.container { display: flex; justify-content: center; align-items: center; }
CSS Grid
Trophy 🏆
.container { display: grid; place-items: center; /* 1 line! */ }
🏆 Grid wins — place-items: center in 1 line
03 / 08
Equal-width columns
Make N columns of equal width. Flex uses flex:1. Grid uses repeat(N, 1fr). Watch the difference when you resize.
🏫 School analogy: Dividing the classroom board into equal sections. Grid draws lines first. Flex stretches each piece after placing them.
Flexbox
CSS Grid
🏆 Grid wins — columns are structurally defined, not stretched
04 / 08
Responsive wrapping
More items than space? Both can wrap to the next row. But auto-fill / auto-fit in Grid handles it without JavaScript.
🏫 School analogy: Students filling seats in a hall — Flex fills one row, wraps to next when full. Grid auto-creates rows based on the floor plan.
Flexbox
CSS Grid
🏆 Grid wins — auto-fill + minmax needs no media query ✅ Flex works too with flex-wrap

🏫 School analogy: Arranging items on a shelf (1D = Flex) vs arranging them on a table grid (2D = Grid).

08 / 08
When to use which?
The golden rule: Flex for content-driven 1D layouts. Grid for structure-driven 2D layouts. Most real pages use both.
Use Flexbox when…
✓ Navbar items, buttons in a row
✓ Centering one element inside another
✓ Items of unknown or dynamic count
✓ Aligning icon + label side by side
✓ Content flows in one direction only
Use CSS Grid when…
✓ Page layout (header, sidebar, main, footer)
✓ Card grids with equal rows and columns
✓ Items spanning multiple columns or rows
✓ Layout must align on both axes
✓ Explicit placement of items in a 2D map
💡 Rule of thumb: Use Grid for the page structure. Use Flex inside each section. They work best together.
