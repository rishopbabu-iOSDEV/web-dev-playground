display: flex
The starting point. Without it, block elements stack vertically. Add display:flex and children instantly line up in a row.
🏫 School analogy: Students in a class standing in a line (flex) vs each sitting separately on their own row of desks (block).

flex-direction
Controls which direction children flow. row is the default (left to right). column stacks them vertically.
🏫 School analogy: Use row for students sitting side-by-side across a single desk. Use column for a queue at the canteen window.

justify-content
Distributes space along the main axis — horizontal when direction is row. Controls how items are spaced from each other.

flex-wrap
By default flex fits everything in one line, squishing items. wrap lets items spill to the next row when there's no room.
🏫 School analogy: Students filling seats in a classroom row — when one row is full they move to the next row. nowrap forces everyone into one row regardless.

The clean way to add space between flex children. No margins, no math, no margin-collapse issues.

flex-grow
Tells an item how much leftover space to absorb. Cell C (outlined) is the one being changed. Higher number = takes more space relative to others.
🏫 School analogy: The main notice board gets flex-grow:2 and takes twice the wall space compared to the smaller boards on each side.

align-self
Overrides align-items for one specific child. The container is set to align-items: flex-start. Cell C (outlined) overrides it independently.
🏫 School analogy: In a row of lockers all aligned to the top, one special locker stretches to the floor independently — the others don't move.

09 / 09
order
Changes the visual order without touching HTML. Default is 0 for all. Lower number = appears first. Negative values push an item before everything else.
🏫 School analogy: The teacher changes the seating chart visually without physically moving any desks — only the visual order changes, not the actual HTML structure.

Combination Guide
The most-used property combinations in real websites. Copy them directly into your projects.
Horizontal Nav Bar navbar
Logo on the left, links pushed to the right. The most common navbar pattern.
display: flex;
justify-content: space-between;
align-items: center;
gap: 16px;
Perfect Center hero / modal
Centers anything — a login card, a modal, a hero message — both vertically and horizontally.
display: flex;
justify-content: center;
align-items: center;
min-height: 100vh;
Card Row with Wrap product grid
Cards sit side-by-side and wrap to the next row on smaller screens.
display: flex;
flex-wrap: wrap;
gap: 20px;
justify-content: flex-start;
Sidebar + Content dashboard
Fixed-width sidebar, main content fills remaining width using flex-grow.
display: flex;
/* sidebar: */
width: 240px; flex-shrink: 0;
/* main: */
flex-grow: 1;
Icon + Text Row list items
An icon sits next to text. The text block wraps without affecting the icon.
display: flex;
align-items: flex-start;
gap: 12px;
/* icon: */
flex-shrink: 0;
Stretchy Search Bar toolbar
Logo and buttons stay natural size; the search input grows to fill available space.
display: flex;
align-items: center;
gap: 10px;
/* search input: */
flex-grow: 1;
Evenly Spaced Tabs bottom nav
Tab items each take equal width across the full container. Common in mobile bottom bars.
display: flex;
justify-content: space-evenly;
align-items: center;
/* each tab: */
flex: 1;
Footer Three Columns footer
Three sections spaced across the footer. Add flex-wrap:wrap to stack on mobile.
display: flex;
justify-content: space-between;
align-items: flex-start;
flex-wrap: wrap;
gap: 32px;
